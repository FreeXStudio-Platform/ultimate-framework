# V2 Contract Compatibility

RC3 treats the 13 V2 schemas as preserved compatibility contracts. Active runtime configuration and executable surfaces remain canonical in their V3 registries and are projected into V2-valid records. Builder-only source, finding, gate, simulation, opportunity, knowledge, projection, scoreboard, and certification records stay in build evidence or handoff so the clean runtime is not contaminated. Historical Notion/Figma availability is not copied; current repository fallback remains authoritative.
