# Generic API/agent host Adapter
**ID:** `ABS.ADAPTER.GENERIC_API`  
**Status:** `UNTESTED`

Map message, tool, state, error, and permission contracts explicitly; deny undeclared capabilities and persist checkpoints outside model memory. This adapter translates all 29 frozen semantic interfaces without becoming authority. It may report `UNSUPPORTED`, `DEGRADED`, `BLOCKED`, or `UNAVAILABLE`; it may never invent host capability, permission, health, or completion.
