# AuditHunt downstream installation profile only — Plain English
This module answers **How can AuditHunt install the framework without being redefined?** It applies three canonical rules: The framework release shall include an AuditHunt installation profile that maps reusable framework modules and adapters without importing AuditHunt implementation or history.; The profile shall not claim AuditHunt facts, modify AuditHunt, certify AuditHunt, or expose restricted AuditHunt evidence; all project-specific state remains externally supplied and verified.; Installation shall be reversible, profile-scoped, versioned, and validated against an explicitly provided AuditHunt baseline in a separate authorized program.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `profile imports stale project claims or implies certification`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
