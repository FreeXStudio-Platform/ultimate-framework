3. Select one of these adapters only after preflight: `ABS.ADAPTER.CHATGPT_CODEX`, `ABS.ADAPTER.CLAUDE_CODE`, `ABS.ADAPTER.CURSOR`, `ABS.ADAPTER.LOCAL_AGENT`, `ABS.ADAPTER.GENERIC_API`.

5. Map existing project state, requirements, decisions, evidence, and release paths to stable IDs.
6. Run schemas, semantic controls, links, negative fixtures, adapter conformance, and a representative end-to-end work packet.
7. Compare active and shadow behavior; resolve conflicts explicitly; obtain required owner approval.
8. Promote only the validated configuration. Preserve the pre-installation checkpoint and migration map.
