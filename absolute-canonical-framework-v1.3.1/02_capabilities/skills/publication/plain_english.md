# Skills, subagents, and delegation contracts — Plain English
This module answers **Is this task bounded enough for a skill, and what stops it?** It applies three canonical rules: A skill shall solve one bounded task class and declare triggers, non-triggers, prerequisites, inputs, workflow, stop conditions, outputs, permissions, validation, failures, fallback, and compatibility.; Delegation shall specify exact scope, governing IDs, allowed data, prohibited actions, output schema/location, evidence, cost, confidentiality, and return path.; Delegated self-report shall not be accepted without independent validation of artifacts, behavior, side effects, and evidence identities.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `skill triggers outside its declared scope`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks.
