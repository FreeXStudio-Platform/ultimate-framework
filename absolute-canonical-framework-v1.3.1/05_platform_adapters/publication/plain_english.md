# ChatGPT/Codex, Claude Code, Cursor, local, and generic adapters — Plain English
This module answers **How does this host translate the framework without changing authority?** It applies three canonical rules: ChatGPT/Codex, Claude Code, Cursor, local-agent, and generic-host adapters shall translate kernel contracts into host-specific files, hooks, permissions, context loading, and commands.; Adapters shall declare required capabilities, limitations, fallbacks, generated artifacts, approval boundaries, and non-authoritative surfaces.; Host-specific behavior shall not contaminate kernel invariants, and adapter compatibility shall be versioned and tested.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `adapter claims untested host capability`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
