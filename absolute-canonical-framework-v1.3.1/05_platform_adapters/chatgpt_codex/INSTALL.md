# Configure ChatGPT/Codex
1. Verify the exact host, account/workspace, version, data policy, tools, repository access, writable paths, network boundary, and model/runtime identity.
2. Start read-only. Register each available capability and leave unavailable mappings `UNTESTED` or `UNSUPPORTED`.
3. Choose a downstream project profile, allocate a distinct project identity, and create a rollback checkpoint.
4. Map durable state and validation commands; never depend on the conversation transcript.
5. Run denial, permission, outage, malformed-input, checkpoint, resume, schema, and representative work-packet tests.
6. Promote the adapter to `CONFORMANT` only with exact evidence for the tested host/configuration hash.
