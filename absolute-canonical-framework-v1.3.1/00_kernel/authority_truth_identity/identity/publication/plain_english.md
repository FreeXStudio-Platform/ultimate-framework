# Project identity and isolation — Plain English
This module answers **Which entity is acting, and can its identity be confused with another layer?** It applies three canonical rules: Builder program, framework, release, profile, adapter, module, and downstream project identities shall use distinct stable namespaces.; Cross-project material shall enter only through an explicit import decision with provenance, scope, confidentiality, and compatibility checks.; Identity conflicts or ambiguous active project scope shall block affected writes until reconciled.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `framework and project identities collide`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
