# AuditHunt Installation Profile
This is a downstream installation contract only. It does **not** modify, redefine, inspect, validate, or certify the AuditHunt implementation. AuditHunt facts, repositories, tools, permissions, architecture, tests, and release state must be discovered afresh under a later explicitly authorized installation program.

## Installation sequence
1. Open a separate AuditHunt installation work packet and define project identity, mission, scope, owner authority, confidentiality, and rollback.
2. Admit the current AuditHunt source read-only; do not import framework-build chats, raw Absolute packages, or historical framework workbench state.
3. Build a project-specific concept and authority map, mapping existing systems rather than replacing them by default.
4. Configure the selected framework profile and host adapter in a shadow namespace.
5. Run project-specific positive, negative, recovery, security, package, and clean-state tests.
6. Obtain independent review of the exact AuditHunt candidate hash before any installation or certification claim.

## Forbidden inheritance
Framework release status, source-estate findings, and package validation do not transfer to AuditHunt. No benchmark, detector, pricing, security, health, or production claim is included here.
