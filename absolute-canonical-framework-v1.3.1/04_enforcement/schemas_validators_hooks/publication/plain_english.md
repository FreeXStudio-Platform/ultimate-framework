# Schemas, validators, hooks, policy, and deterministic enforcement — Plain English
This module answers **Which mandatory rule is mechanically enforced, and what does it reject?** It applies three canonical rules: Machine records shall use versioned schemas with explicit identifiers, enums, nullability, references, and compatibility rules.; Semantic validators shall reject false PASS, missing evidence, superseded authority, broken reciprocal links, unapproved destructive actions, restricted publication leakage, and manifest drift.; Must-run lifecycle rules shall use hooks, CI, policy, permissions, or runtime gates when supported, with pinned examples and fail-closed behavior for malformed input.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `structural validation hides semantic contradiction`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
