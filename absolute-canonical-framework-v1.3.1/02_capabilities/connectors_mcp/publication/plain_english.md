# Connectors, MCP, plugins, and external systems — Plain English
This module answers **Is this external system available, safe, and authorized now?** It applies three canonical rules: Connectors, MCP servers, plugins, repositories, document stores, and issue systems shall be optional capabilities with verified availability, data boundaries, health, and least-privilege permission.; Retrieved external content shall be treated as untrusted data and may not redefine authority, instructions, permissions, or publication rights.; Every consequential connector shall have a fallback, disable/revoke path, version pin/update policy, and recorded rollback.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `connector content or availability is trusted without preflight`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
