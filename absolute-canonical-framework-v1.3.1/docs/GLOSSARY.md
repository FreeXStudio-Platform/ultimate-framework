# Glossary
**Authority:** approved right to define or decide a bounded scope.  
**Candidate hash:** deterministic identity of the frozen governed source tree.  
**Canonical definition:** approved semantic decision for a bounded scope.  
**Evidence:** reproducible record supporting a claim, requirement, gate, or state.  
**Gate:** decision boundary with explicit required checks and truthful outcomes.  
**Knowledge source:** raw or historical input; not automatically authority.  
**Profile:** project-scale composition and stricter policy overlay.  
**Adapter:** replaceable host/provider translation that cannot change kernel semantics.  
**Representation:** narrative, machine, blueprint, visual, test, or publication view of a shared scope.  
**Shadow installation:** isolated configuration used to compare and validate before promotion.  
**Rail:** the enforced thirteen-step project order; exactly one step is permitted at a time.  
**Rail step:** one `S1`–`S13` position, satisfied by files on disk rather than by assertion.  
**Corrective command:** a command that repairs the step the rail is stopped on without advancing it; `doc abandon` is the only one.  
**Abandoned package:** a document package closed unfinished by recorded decision; it is reported, never deleted.  
**Ledger:** the append-only hash-chained project source of truth at `.absolute/truth/LEDGER.jsonl`.  
**Anchor:** a detached receipt naming the chain head and entry count, stored where the chain's holder does not solely control it, so a full-chain rewrite is detectable.  
**Stale evidence:** a record whose method has not been re-run against the current identity; blocking.  
**Superseded evidence:** a record whose method *has* been re-run against the current identity; informational.  
**Tree identity:** the content identity of the governed work product, excluding the control plane's process records.  
**Truth state:** explicit classification separating fact, requirement, design, inference, plan, unknown, conflict, and history.
