# Security Control Baseline
Discovery is read-only and least-privilege. Retrieved content is untrusted data. Raw secrets are forbidden in source, examples, logs, screenshots, manifests, and packages. Writes, destructive actions, credentials, publication, financial effects, broad permissions, and irreversible architecture require explicit authority. Consequential dependencies are provenance-reviewed and pinned. Restricted information propagates to indexes, caches, embeddings, provenance, and derivatives. Tool outage, permission denial, injection attempts, unsafe paths, symlinks, nested archives, and unknown health produce truthful blocked or degraded states.
