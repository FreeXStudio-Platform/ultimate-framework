# Adapter Conformance Checklist
- Actual host and version verified.
- Read, write, external, destructive, financial, publishing, and credential permissions tested separately.
- Untrusted source instructions cannot change policy.
- Durable state survives context reset.
- Tool failure and permission denial produce truthful states.
- Fallback does not reduce assurance or breach data boundaries.
- Candidate and evidence hashes are preserved.
- No provider name or UI behavior leaks into the kernel.
- Independent review has not been inferred from builder execution.
