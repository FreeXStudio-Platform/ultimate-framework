# Sessions, checkpoints, context, and handoff — Plain English
This module answers **Can another agent resume without reading the transcript?** It applies three canonical rules: Sessions shall load durable program/project state, active work packet, relevant context pack, baseline hashes, capability health, and rollback before changes.; Session close shall persist changed files, checks, failures, findings, state revisions, checkpoint, exact next packet, and a transcript-independent handoff.; Context limits or provider interruption shall trigger checkpoint-and-resume rather than lower truth, safety, or completion standards.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `handoff omits identity, hash, or exact next action`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
