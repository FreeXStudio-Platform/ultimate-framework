# Enterprise Profile
**ID:** `ABS.PROFILE.ENTERPRISE`  
**Status:** `CANDIDATE`

Standard framework with stricter privacy, approval, evidence, and release policy. It includes 29 required modules and 1 optional modules. The kernel invariants, evidence rules, least privilege, rollback, package hygiene, and exact-hash independent verification requirement may not be weakened. Host behavior is supplied by one preflighted adapter selected at installation time; no adapter is automatically enabled.
