# Standard Profile
**ID:** `ABS.PROFILE.STANDARD`  
**Status:** `CANDIDATE`

Default complete operating framework. It includes 29 required modules and 2 optional modules. The kernel invariants, evidence rules, least privilege, rollback, package hygiene, and exact-hash independent verification requirement may not be weakened. Host behavior is supplied by one preflighted adapter selected at installation time; no adapter is automatically enabled.
