# Registries, graph, indexes, context packs, and retrieval — Plain English
This module answers **Can every concept, requirement, artifact, test, and release be traced?** It applies three canonical rules: The framework shall define versioned registries and a source-controlled typed graph connecting sources, concepts, modules, requirements, claims, decisions, capabilities, artifacts, tests, evidence, profiles, and releases.; Graph edges shall record source, target, type, direction, evidence, confidence, lifecycle, and last verified identity, and required provenance/impact queries shall be testable.; Context packs shall be compact evidence-linked navigation aids and shall never outrank canonical sources; vector or graph-database infrastructure remains threshold-triggered.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `dangling or stale projection is treated as authority`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
