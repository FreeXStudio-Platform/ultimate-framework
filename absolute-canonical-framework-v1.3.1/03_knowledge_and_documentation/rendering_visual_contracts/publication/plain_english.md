# Visual semantics, routing, rendering, and accessibility — Plain English
This module answers **What reader question does this visual answer from governed data?** It applies three canonical rules: Every visual shall answer a defined reader question using a structured semantic source, declared data/evidence, visual grammar, semantic encodings, accessibility, renderer identity, and output manifest.; Visual routing shall select the simplest sufficient approved renderer; 3D, animation, and motion are allowed only when they materially improve understanding.; Generated visuals shall have editable semantic source and static accessible fallback, and rendering shall be validated for meaning, parity, labels, contrast, navigation, and export.
It first checks identity, scope, authority, permission, freshness, and rollback; performs one bounded operation; records evidence and limitations; and reports a truthful state. The key failure is `decorative or misleading visual substitutes for evidence`. The response is to stop the affected action, preserve the finding, restore a safe checkpoint where needed, fix the canonical source, and rerun affected checks. This release remains a candidate pending independent review.
